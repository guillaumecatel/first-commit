## [Unreleased]

### Added

- Initial DTCG token foundation for colors and layout.
- Light and dark theme token sets.
- Token resolver configuration using the DTCG Resolver format.
- CSS custom property generation with automatic color-scheme detection.
- JavaScript token resolver with generated TypeScript declarations.
- Token validation and linting through Terrazzo.
- Workspace package structure and development scripts.
- Tailwind v4 compatible CSS output.
